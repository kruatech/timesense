# Support

- **Questions / usage help:** open a [GitHub Discussion](https://github.com/kruatech/timesense/discussions) or an issue.
- **Bugs:** use the Bug report issue template.
- **Feature requests:** use the Feature request issue template.

Before filing, please check the README "Known limitations" section — several
behaviours (timezone-naive output, smart-hour interpretation, heuristic
`parse_multi`) are intentional and documented.
