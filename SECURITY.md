# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |

## Reporting a Vulnerability

TimeSense is a pure-Python, offline library with no network access, no
`eval`/`exec`, and no runtime dependencies (morphology is optional). The attack
surface is small, but if you find a security issue:

- Email **a@krutilin.pro** with a description and steps to reproduce.
- Please do **not** open a public issue for security-sensitive reports.
- You can expect an acknowledgement within a few days.

Do not include exploit details in public channels until a fix is released.
